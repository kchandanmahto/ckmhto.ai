# Contributing to ckmhto.ai

Thank you for your interest in contributing to **ckmhto.ai**.

This repository is primarily a personal portfolio and AI engineering
project. Contributions, technical suggestions, bug reports and
improvements are welcome when they are relevant to the project.

---

## Before You Contribute

Before making changes, please:

1. Read this document.
2. Check existing issues and pull requests.
3. Avoid duplicating existing work.
4. Keep changes focused and understandable.
5. Never commit secrets or private credentials.
